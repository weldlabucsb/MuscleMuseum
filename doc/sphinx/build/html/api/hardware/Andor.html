static andorLoop(cq, cdq)#

Worker loop managing Andor SDK calls.

Sends a worker queue back to the client, initializes SDK, and handles messages for parameter setup, Start, data transfer, and Stop. Uses parallel.pool.PollableDataQueue for communication. Send the worker queue to the client
