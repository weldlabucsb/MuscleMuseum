Acquisition

Acquisition#

class Acquisition(acqName)[source]#

Bases: handle, matlab.mixin.SetGetExactNames

Acquisition camera acquisition base class.

Describes camera properties and saving images from a camera of interest. Implements helpers for connect/configure/callback/start/stop and image utilities. Subclasses (e.g., Andor) override specifics.

Notes:

Configuration is loaded from Config.mat by Acquisition() and applied via an internal setter. Quantum efficiency can be interpolated by QuantumEfficiency().
