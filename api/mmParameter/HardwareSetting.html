HardwareSetting

HardwareSetting#

class HardwareSetting#

Bases: MmParameter

HardwareSetting stores per-hardware per-channel settings and bindings.

Each row identifies a hardware device (HardwareID), a channel (ChannelNumber), a setting Name, and its value. Values can be provided either as a literal DefaultValue (stored as TEXT) or by referencing a VariableList entry via VariableID, in which case the effective value will be resolved dynamically.

readSetting(hwId)#

Read effective values for all settings of a hardware device.

Returns a table with columns Name, ChannelNumber, VariableID, Value where Value is resolved from VariableList when VariableID != 0, otherwise equals DefaultValue cast to its declared type.
